# 0001 Offline-first fictional editorial simulation

Status: accepted pilot constraints and reversible editor-role default.

The first playable is one static browser episode. Original, fictional case data is separate from the interaction engine. It has no network dependency at runtime and stores at most local progress. It has no account, student identifier, telemetry, external platform or real publishing. The student exercises source checks, warranted restraint and accountable updates.

An editor is the pilot role because the educational task is to weigh evidence and decide what can responsibly be communicated. A citizen story and a multi-role version are viable later; a playable antagonist or popularity score would impede the first milestone.

Use a separate GitHub Pages publishing branch whose tree contains only the tested playable assets. The development repository is public by owner instruction; publishing must still exclude supplied reference art, raw internal drafts and student content. Avoid paid builds and remote libraries.
