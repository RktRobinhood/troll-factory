# Troll Factory

An independently authored browser game about editorial judgment, evidence and civic responsibility. A short case asks students to investigate a claim, decide what a newsroom can responsibly say, and repair the public record if the evidence changes.

**Milestone:** one upper-secondary pilot episode. The game is fictional, not affiliated with Yle, and contains no historical source artwork or code. No accounts, telemetry, external posting or student data collection.
